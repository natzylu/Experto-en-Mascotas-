Experto en Mascotas
Sistema experto en Python que recomienda una mascota según espacio, tiempo, presupuesto, experiencia, actividad física, presencia de niños y preferencia.
Ejecutar en GitHub Codespaces
Abra el repositorio en GitHub.
Seleccione Code > Codespaces > Create codespace on main.
En la terminal ejecute:
```bash
python main.py
```
Las consultas se guardan en `historial_mascotas.csv`.
> Nota: Codespaces funciona mejor con la versión de consola. Tkinter requiere una pantalla gráfica y no se inicia desde `main.py`.
